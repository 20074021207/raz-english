# 儿童英语例句语料生成规则（审计脚本会逐条校验，违反即拒绝）

## 任务
为每个目标词编写 **3 条英语例句 + 中文翻译**，读者是中国四年级学生（9-10 岁）英语启蒙阶段。

## 硬性规则
1. **包含目标词**：每句必须包含目标词本身或其自然屈折形式（复数 -s/-es、动词 -ing/-ed/-ed、所有格 's）。
2. **词汇墙**：除目标词及其屈折外，句中所有单词必须来自 `allowed.json` 的 `allowed` 数组
   （大小写不敏感；墙内词同样允许屈折：cats、played、running、bigger 等）。
3. **禁止**：专有名词（人名/地名/品牌/动画角色名）、生僻缩写。允许的缩写仅限：
   don't, can't, it's, that's, let's, I'm, you're, we're, they're, he's, she's, isn't, aren't, what's, here's, there's。
4. **句长**：每句 3-9 个单词；首字母大写；句尾标点 . ! ? 之一。
5. **句式多样**：同一单词的 3 句句式必须互不相同（如：陈述 / 疑问 / 感叹或祈使），
   场景要具体有画面感（动物、食物、家、学校、公园、运动、天气……），避免三句都是 "I like/see X"。
6. **多义词用小学生核心义**：run=跑（不是经营）、left=左边（不是离开）、orange=橙色/橘子、play=玩、band=带子/乐队。
7. **中文翻译**：自然、口语化的儿童表达，禁止翻译腔；使用中文全角标点。

## 输出格式
写一个**严格 JSON** 文件（UTF-8，双引号，无注释，无尾逗号）：

```json
{"word1": [["English sentence.", "中文翻译。"], ["...", "..."], ["...", "..."]], "word2": [...]}
```

- 键名必须与分配给你的词表完全一致（小写原形）
- 每词恰好 3 条
- 除 JSON 外不要写任何其他内容到该文件

## 自查清单（写完后逐条过）
- [ ] 每句含目标词（或屈折）
- [ ] 逐词核对词汇墙（尤其介词/动词是否超墙）
- [ ] 无专有名词、无规则外缩写
- [ ] 3 句句式互不相同
- [ ] JSON 可被 `JSON.parse` 解析
